# DevOps Capstone - Account Management REST API

![Build Status](https://github.com/dhrutimahadik5106/devops-capstone-accounts/actions/workflows/ci-build.yaml/badge.svg)

## Project Description

This project develops an Account Management REST API
using Python and Flask.

The project demonstrates DevOps practices including
Agile planning, automated testing, CI/CD, security,
Docker, Kubernetes, and Tekton pipelines.

## Features

- Create an account
- Read an account
- List all accounts
- Update an account
- Delete an account

## Technology Stack

- Python
- Flask
- GitHub Actions
- Docker
- Kubernetes
- Tekton
